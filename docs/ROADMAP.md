# muud view — 로드맵

지금까지 나온 아이디어를 모두 모아 버전별로 묶었습니다. 각 버전은 그 자체로 쓸 수 있는 상태로 완성해서 릴리스합니다.
꿀뷰에 있던 동작은 공개된 단축키 도움말 기준으로 맞추고, 구현은 처음부터 새로 합니다 ([SPEC.md](SPEC.md)의 클린룸 원칙).

표기: `꿀뷰` 꿀뷰에 있던 동작 · `NEW` 꿀뷰에 없던 기능

---

## v0.1 — MVP ✅ 완료

빠른 넘김(앞뒤 미리 디코딩), 탐색기식 정렬, 맞춤/폭 맞춤/100%/커서 기준 확대, 회전·뒤집기, EXIF 자동 회전,
움직이는 GIF/WebP, 정보 패널(해상도·카메라·노출·히스토그램·GPS), F1 단축키 표, 휴지통 삭제,
이미지/EXIF/경로 복사, 슬라이드쇼, 배경 전환, 설정 저장, 단일 exe, 라이선스 검사 CI, 릴리스 자동화.

---

## v0.2 — 매일 쓰는 뷰어

꿀뷰를 바로 대체할 수 있는 수준이 목표.

| 기능 | 내용 | 키 |
|---|---|---|
| 실물 점검 | 고해상도 배율, 파일 열기 창, 탐색기 열기, 휴지통, **한글 입력기 켜진 상태의 단축키** 확인 (체크리스트 → `docs/CHECKLIST.md`) | |
| 창 하나로 열기 | 이미 열린 창이 있으면 새 창 대신 그 창에서 열기 (설정으로 끌 수 있게) | |
| **Windows 통합** | 아래 항목을 설정 화면의 "Windows 통합" 한 곳에서 켜고 끄기 | |
| 기본 앱 등록 `꿀뷰` | 확장자별 "연결 프로그램" 후보로 등록 → Windows 기본 앱 설정 화면을 바로 열어 선택. Windows 10/11은 앱이 기본 앱을 몰래 바꾸는 걸 막아 두어서, 마지막 클릭은 사용자가 해야 함 | |
| 확장자 선택 | JPG·PNG·GIF·WebP… 중 연결할 것만 고르기 | |
| 우클릭 메뉴 `꿀뷰` | 이미지: "muud view로 열기", 폴더: "muud view로 폴더 보기" | |
| 시작 메뉴 바로가기 | 검색으로 실행할 수 있게 | |
| 등록 해제 | 위 항목을 한 번에 깨끗이 제거 (프로그램을 지우기 전에) | |
| 포터블 모드 | exe 옆에 `portable` 파일이 있으면 설정을 exe 폴더에 저장 (USB·공용 PC용) | |
| 설치 프로그램 (선택) | 포터블 zip과 별도로, 설치 시 위 항목을 자동 처리하는 설치판 | |
| 하단 바 `꿀뷰` | 마우스를 아래로 가져가면 나타났다 스르륵 사라짐, 고정 가능. 상단 바도 같은 방식 | `~` 하단 고정, `` ` `` 상단 고정 |
| 진행 바 | 점선 + 지나온 구간 실선, `012 / 120`, 클릭·드래그로 이동, 올리면 파일명 표시. 바가 숨겨져도 맨 아래 2px 진행선 | |
| 하단 버튼 | 이전/다음 · 축소/100%/확대/맞춤 · 회전 · 전체화면 · 정보 패널 (알약 버튼) | |
| 사진보관함 `꿀뷰` | 보관함 1 복사 / 1로 이동 / 2 복사 | `Insert` / `Ctrl+Insert` / `Shift+Insert` |
| 사진보관함 확장 `NEW` | 보관함 3~9, 같은 이름이면 자동 `(2)`, 완료 알림에 보관함 이름, 기본 위치 `사진\muud-view` | `Alt+1`~`Alt+9` (안) |
| 되돌리기 `NEW` | 방금 한 이동·휴지통 삭제 되돌리기 | `Ctrl+Z` |
| 축소 이미지 복사 `꿀뷰` | 메신저용 작은 크기로 복사 | `Ctrl+Alt+C` |
| 파일째 복사 `NEW` | 탐색기엔 파일로, 채팅창엔 이미지로 붙여넣어지게 | `Ctrl+C`에 같이 담기 (안) |
| 원본 해상도 복사 | 큰 이미지도 축소하지 않은 원본으로 복사 | |
| 클립보드 이미지 보기 `NEW` | 캡처한 화면을 저장 없이 바로 열기 | `Ctrl+V` |
| 오류 로그 | `%LOCALAPPDATA%\muud-view\log.txt`, 크기 제한 | |
| 코드 정리 | `app.rs`(약 1,000줄) 분리, 넘김·캐시·보관함 동작 테스트 추가 | |
